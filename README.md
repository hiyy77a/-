# 墨剑诀 · Ink Blade

一款武侠水墨风的**打字战斗**网页游戏。以字为剑，以键为锋 —— 每一次正确的键入，都是剑客的一记突进挥剑。

## 怎么玩

直接用浏览器打开 `index.html`，按 **回车** 开始。

- 屏幕正下方是一段英文长文本，依次正确键入其中的字符；
- 每命中一个字符，左侧的剑客会**向前突进一小段并挥出一道剑气**，攻击完成后回到原位；
- 剑气命中右侧御剑悬浮、不断后退漂移的敌人，对其造成伤害；
- 连击越高，单次伤害越高（每 15 连击 +1，最高 +3）；
- **不间断连击每满 100**，自动发动全屏终结奥义「斩」——画面化为水墨，墨笔巨字当空，对敌造成巨额伤害；
- 输入错误则文本条震动、连击归零；
- 击破敌人进入下一阵，敌人血量逐阵提升；打完一篇文本自动衔接下一篇；
- **Esc** 暂停，**M** 静音。

## 阵法体系

- **每 5 阵为魔王阵**，六大魔王依序登场（Q 版立绘造型）、各怀绝技与专属招式动作、绝不重样：

  | 阵 | 魔王 | 特征 | 招式动作 |
  | --- | --- | --- | --- |
  | 5 | 血刀魔君 | 红发爆炸头赤目，鬼面重甲，赤纹发光巨刀，脚踏赤云 | 周期高举巨刀抡劈，震屏溅血雾 |
  | 10 | 幽泉琴魔 | 黑长直坏笑，石座抚琴，身后暗紫妖气旋涡隐现鬼面 | 拨弦音爆，赤色音波环扩散 |
  | 15 | 纸伞鬼姬 | 白发顶髻骷髅簪，红眸额印，红光涡旋纸伞，鬼火相随 | 符纸燃焰四射，纸伞红光流转 |
  | 20 | 铁血战侯 | 金目兜鍪赤缨，甲纹肩吞，背插「戰」字大旗 | 长枪周期突刺，枪风扑面 |
  | 25 | 白骨禅魔 | 闭目怪僧，袈裟佛珠，Q 版骷髅三连环绕 | 梵音青环脉冲，磷火飘散 |
  | 30 | 墨龙真君 | 龙角紫眸白须老祖，墨龙盘绕周身 | 龙首昂首咆哮，喷吐墨气 |

  魔王血量为同阵普通敌人的 2.4 倍，击破奖励大幅提升。

- **每 5 阵更换一方天地**（击破魔王即转场），流程依次为：**竹林 → 大漠 → 沧海 → 古镇 → 云海**，之后循环。每幕拥有独立的天色、远景、视差元素与地面细节（竹叶婆娑 / 大漠孤烟 / 帆影浪光 / 黛瓦红灯 / 云涛山尖）。

## 玩法与画面

| 要素 | 实现 |
| --- | --- |
| 交互 | 纯键盘：正确命中文本字符 → 突进 + 攻击 → 回位 |
| 角色 | Q 版 2D 动漫代码建模：大头身比、大眼高光、发光眼眸——白衣剑客（马尾红绳、尖刘海、Q 版大剑）与御剑黑衣刺客（大斗笠、面巾、发光赤目） |
| 攻击特效 | 全水墨系：浓淡双笔墨月牙剑气 + 朱砂气旋 + 飞溅墨点、墨烟卷缕、墨色/朱砂火花、冲击波环、挥剑三层墨韵弧光、屏幕震动 |
| 终结奥义 | 百连触发：全屏水墨化、慢动作、横贯斩击流光、墨笔巨字「斩」+ 溅墨 + 朱印落款 |
| 数值 | 分数、连击（含奥义充能提示）、WPM、准确率实时统计 |

## 技术说明

- 单文件实现（`index.html`），无任何外部依赖，Canvas 2D 渲染；
- 角色采用参数化平面建模：髋/肩/头锚点 + 双骨 IK 解算四肢关节，配合宽度渐变的"毛笔"笔触与分层衣饰路径绘制，奔跑、弓步突进、挥剑均为程序化动画；
- 六位 Boss 均为参照 Q 版立绘独立手写的矢量造型，带周期招式动作与专属环境粒子/妖气发射器；
- 五幕场景由种子随机生成的山脊/沙丘折线、竹竿、帆影、屋舍、云涛等元素构成，按不同速度视差滚动；
- 音效由 WebAudio 实时合成（挥剑、命中、失误、破阵锣、魔王闷鼓、奥义轰鸣），无音频资源文件；
- `window.__dbg`（setWave / ult / state）为自动化测试钩子。
