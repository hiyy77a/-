# 墨剑诀 · Ink Blade

一款武侠水墨风的**打字战斗**网页游戏。以字为剑，以键为锋 —— 每一次正确的键入，都是剑客的一记突进挥剑。

## 怎么玩

直接用浏览器打开 `index.html`，按 **回车** 开始。

- 屏幕正下方是一段英文长文本，依次正确键入其中的字符；
- 每命中一个字符，左侧的剑客会**向前突进一小段并挥出一道剑气**，攻击完成后回到原位；
- 剑气命中右侧御剑悬浮、不断后退漂移的黑衣人，对其造成伤害；
- 连击越高，单次伤害越高（每 15 连击 +1，最高 +3）；
- 输入错误则文本条震动、连击归零；
- 击破敌人进入下一阵，敌人血量逐阵提升；打完一篇文本自动衔接下一篇；
- **Esc** 暂停，**M** 静音。

## 玩法与画面

| 要素 | 实现 |
| --- | --- |
| 交互 | 纯键盘：正确命中文本字符 → 突进 + 攻击 → 回位 |
| 角色 | 左侧奔跑的剑客（玩家）、右侧御剑后退的黑衣人（敌人） |
| 场景 | 2D 横版：远山三层视差滚动、竹林、云雾、飞鸟、宣纸纹理与晕染 |
| 美术 | 武侠水墨风，角色为代码化平面建模（双骨 IK 四肢 + 毛笔笔触渲染） |
| 数值 | 分数、连击、WPM、准确率实时统计 |

## 技术说明

- 单文件实现（`index.html`），无任何外部依赖，Canvas 2D 渲染；
- 角色采用参数化平面建模：髋/肩/头锚点 + 双骨 IK 解算四肢关节，配合宽度渐变的"毛笔"笔触绘制，奔跑、弓步突进、挥剑均为程序化动画；
- 背景由种子随机生成的山脊折线、竹竿分段与噪点宣纸纹理构成，按不同速度视差滚动；
- 音效由 WebAudio 实时合成（挥剑、命中、失误、破阵锣声），无音频资源文件。
